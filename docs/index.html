Synapse Static API

Add Synapse to any site with one snippet. No server, no build step.

Quick start

Paste this before </body> on any page. It adds a floating Play button that opens Synapse fullscreen.

<script src="{{BASE}}/api/v1/synapse.js"></script>

Embed inline instead

Put a container where you want it, then load the script in inline mode:

<div id="synapse" style="height:600px"></div>
<script src="{{BASE}}/api/v1/synapse.js" data-mode="inline"></script>

Script options (data attributes)

AttributeDefaultDescription
data-modebuttonbutton floating button + fullscreen overlay, inline iframe in a container, manual nothing until you call the JS API.
data-target#synapseCSS selector of the container (inline mode).
data-labelPlayButton text.
data-positionbottom-rightbottom-right or bottom-left.
data-height600pxHeight used if the inline container has none.
data-guesttrueVisitors who aren't signed in are logged in automatically as a shared guest account. Set false to show the normal Sign In button instead.
data-baseautoWhere Synapse is hosted. Auto-detected from the script URL; only set it if you self-host the script separately.

JavaScript API

CallDescription
Synapse.open()Open the fullscreen overlay (Esc or the × closes it).
Synapse.close()Close the overlay.
Synapse.mount(target)Mount an inline iframe into a selector or element. Returns the iframe.
Synapse.destroy()Remove the button, overlay and mounted iframes.
Synapse.config({...})Change options at runtime (call before open/mount).
Synapse.url()Returns the launcher URL.
Synapse.on(event, fn) / offEvents: open, close, ready (iframe loaded).
<script src="{{BASE}}/api/v1/synapse.js" data-mode="manual"></script>
<button onclick="Synapse.open()">Launch</button>

Hosting

Upload the whole folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, or any web server). The {{BASE}} in the snippets above fills in automatically from wherever this page is served, so they are copy-ready.

Notes

The launcher signs in through CloudMoon's own backend, so players need a CloudMoon account and the site must be served over HTTPS for streaming (fullscreen, audio, gamepad) to work. The SDK only embeds the launcher; it does not change how that backend works.
